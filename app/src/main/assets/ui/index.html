This is a test port. The launcher runs on Android; Wine runs the Windows game.

First launch

  1. Complete the three steps in Setup.
  2. In your selected Windows runtime, create or use a container that runs 32-bit Windows programs. Confirm the game folder is mapped to a drive.
  3. Return to Play, choose the server and sign in.
  4. Tap Play.
  5. Start your container and open Launch_OpenFusion.cmd in the OpenFusion folder.

The launch file stays in your game folder for reuse. Play updates its settings. Remembered accounts now request a fresh game login when FFRunner starts, so the same launch file can be reused while the Android bridge is running. Signing out clears the saved launch file.

A reusable Winlator shortcut

Create a shortcut to C:\windows\system32\cmd.exe in your container. In its launch arguments, enter:

/d /c "D:\OpenFusion\Launch_OpenFusion.cmd"

After preparing a game in this app, tap that shortcut in your Windows runtime. Enable direct launch only if your installed build supports it.

If the game doesn't start

This launcher writes Launch_OpenFusion.cmd to start ffrunner-android.exe. After updating, prepare a fresh launch file; old scripts are not updated until you prepare again.

  • Missing file: use Check existing runner files, then reinstall if needed.
  • Can't find the launch file: confirm the drive mapping and prepare again.
  • Black screen or crash: start with Direct3D 9, 960 × 540 and 30 FPS. Your runtime's renderer, drivers, Wine version and 32-bit support still determine game compatibility.
  • Downloads stop: leave this app running. Allow its notification and check Android's battery settings if the service gets stopped.
  • Sign-in bridge unavailable: keep this Android app running while the game starts. If Android stopped the foreground service, press Play here once to restart it.
  • Controller axes broken: enable the Controller → keyboard/mouse compatibility in Setup and use XInput-only in Ludashi/GameNative/Winlator to avoid duplicate DirectInput events.

Game details are in ffrunner.log beside ffrunner-android.exe. That game log may include account information; review it before sharing.
